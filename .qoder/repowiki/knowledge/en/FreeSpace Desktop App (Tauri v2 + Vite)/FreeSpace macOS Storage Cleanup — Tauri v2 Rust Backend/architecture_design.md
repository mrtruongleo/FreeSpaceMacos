Single Cargo crate (`freespace-macos`) built as `staticlib`+`cdylib`+`rlib` so Tauri embeds it into the native binary. `src/main.rs` is a thin entry point that calls `freespace_lib::run()`; all business logic lives in `src/lib.rs`, which exposes the public IPC surface via `#[tauri::command]` functions. The crate is split into four logical layers inside one file: (1) data types (`SafetyLevel`, `CleanupItem`, `SubCleanupItem`, `DiskUsage`, `ScanResult`, `DeleteResult`, `LargeFile`, `PlatformInfo`) derived with `serde::{Serialize, Deserialize}`; (2) shared helpers (`get_dir_size`, `expand_home`, `scan_children_direct`, `scan_location`, `is_category_root`, `delete_target`, `delete_dir_contents_resilient`); (3) platform-specific command implementations gated by `#[cfg(target_os = "...")]` blocks (`scan_system` has separate macOS/Windows bodies, `get_disk_usage` uses `libc::statfs` on macOS and `windows_sys::GetDiskFreeSpaceExW` on Windows, `reveal_path` shells out to `open -R` vs `explorer /select,...`); (4) Tauri runtime wiring through `tauri.conf.json` (window config, CSP, bundle icons, dev URL `http://localhost:1420`). Capability-based permissions are declared in `capabilities/default.json` (core:default + opener:default). A `build.rs` invokes `tauri_build::build()` to generate schema files under `gen/schemas/`. Cross-platform behavior is centralized through `is_category_root`'s slash-and-lowercase normalization plus `expand_home` so the same rule set works over `/Users/...` and `C:\Users\...` paths.
