- Cross-platform variants are expressed with `#[cfg(target_os = "...")]` blocks around both function definitions (e.g. separate `scan_system` implementations for macOS and Windows) and inline code sections inside shared functions like `get_disk_usage` and `reveal_path`.
- User-facing strings (descriptions, safety tips, category labels) are written in Vietnamese and embedded directly in the `scan_location` call arguments rather than loaded from localization files.
- Cleanup targets are modeled as `CleanupItem` structs produced by a single `scan_location` helper, each tagged with a `SafetyLevel` enum (`Safe` or `NeedsReview`) and grouped into `safe_items` / `review_items` vectors before being assembled into a `ScanResult`.
- Path inputs accept `~/` prefixes and are normalized through `expand_home` plus `is_category_root`'s slash-and-lowercase normalization so the same rule set works across macOS `/Users/...` and Windows `C:\Users\...` paths.
- Destructive operations use a resilient two-phase strategy: attempt `remove_dir_all` / `remove_file`, and on failure fall back to recursively deleting children then removing the empty directory, accumulating freed bytes, deleted counts, and error messages into a `DeleteResult`-style tuple.
