Standard Tauri v2 layout: the TypeScript/Vite frontend under `src/` (entry `index.html` → `/src/main.ts`) communicates with the Rust backend under `src-tauri/` exclusively through Tauri IPC commands exposed via `@tauri-apps/api`; the backend owns all filesystem operations while the frontend only renders UI. `vite.config.ts` pins dev server port 1420, HMR port 1421, and excludes `src-tauri/**` from watching so the two sides are built independently and linked at runtime by Tauri's CLI.
