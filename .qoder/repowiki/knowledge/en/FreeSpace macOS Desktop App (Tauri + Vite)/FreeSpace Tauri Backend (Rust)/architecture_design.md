Single-crate Tauri v2 application under `src-tauri/`. `main.rs` is a thin entry point that delegates to `freespace_lib::run()`; all business logic lives in `lib.rs`, which defines the public API surface as `#[tauri::command]` functions. The crate is built as a staticlib/cdylib/rlib so Tauri can embed it into the native binary. Cross-platform behavior is split via `#[cfg(target_os = "...")]` blocks: macOS uses `libc::statfs` and `open -R`; Windows uses `windows-sys::Win32::Storage::FileSystem::GetDiskFreeSpaceExW` and `explorer /select,...`. A build script (`build.rs`) invokes `tauri_build::build()` to generate the schema files under `gen/schemas/`. Capability-based permissions are declared in `capabilities/default.json` (core:default + opener:default) and bound to the `main` window. The frontend is an external web app served from `../dist` during dev (`beforeDevCommand: npm run dev`, `devUrl: http://localhost:1420`). Icons for macOS, Windows, iOS, and Android live under `icons/` and are referenced by `tauri.conf.json`.
