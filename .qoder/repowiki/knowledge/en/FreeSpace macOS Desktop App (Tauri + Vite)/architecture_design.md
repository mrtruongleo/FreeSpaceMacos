The project is a standard Tauri v2 application: `src/` holds the TypeScript frontend (entry `index.html` → `/src/main.ts`) built by Vite and served on port 1420 with HMR on 1421; the Rust backend lives in `src-tauri/` and is excluded from Vite's watcher. The two sides communicate exclusively through Tauri's IPC — the frontend calls Rust commands exposed by the backend via `@tauri-apps/api`, while the backend owns all filesystem operations (scan, list large files, delete). `vite.config.ts` pins the dev server to fixed ports and ignores `src-tauri/**`; `tsconfig.json` enforces strict TS with `noEmit` so Vite performs compilation at runtime. A separate Python script (`generate_icon.py`) produces the app icon asset referenced by `index.html`.
