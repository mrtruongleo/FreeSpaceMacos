## Approach

The FreeSpace app uses a **single global stylesheet** (`src/styles.css`, ~1550 lines) loaded directly from `index.html` via `<link rel="stylesheet" href="/src/styles.css" />`. There is no CSS-in-JS, no component-scoped CSS, no SCSS/Sass pipeline, and no design-system package. Styling is plain CSS with CSS custom properties (CSS variables) acting as the sole design-token layer.

No third-party UI library or CSS framework is present in `package.json`; the only dependencies are `@tauri-apps/api`, `@tauri-apps/plugin-opener`, Vite, and TypeScript. The build script runs `tsc && vite build`, so styles are compiled by Vite's default CSS handling — no PostCSS/Tailwind config exists.

## Design Tokens (`:root`)

All visual values are centralized in `:root` at the top of `src/styles.css`:

- **Colors**: semantic background tokens (`--bg-primary`, `--bg-secondary`, `--bg-card`, `--bg-card-hover`, `--bg-card-border`), accent palette (`--accent-blue`, `--accent-green`, `--accent-amber`, `--accent-red`, `--accent-purple`) plus their dimmed variants (`--accent-*-dim`), text tokens (`--text-primary`, `--text-secondary`, `--text-muted`), and ring colors (`--ring-used`, `--ring-free`).
- **Spacing/radius**: `--radius-sm/md/lg/xl` (8–20px).
- **Transitions**: `--transition-fast/normal/slow` using `cubic-bezier(0.4, 0, 0.2, 1)` at 150/250/400ms.
- **Typography**: system font stack targeting Apple platforms (`-apple-system, BlinkMacSystemFont, "SF Pro Display", "SF Pro Text", "Helvetica Neue", system-ui, sans-serif`), base size 13px, line-height 1.5, antialiased rendering.

These variables are the only abstraction boundary; every color, radius, and transition in the rest of the file references them.

## Visual Style & Conventions

- **Dark theme**: `--bg-primary: #0d0f14` is the page background; cards use translucent backgrounds (`rgba(20, 24, 36, 0.7)`) with `backdrop-filter: blur(20px)` for a glassmorphism effect.
- **Glass cards**: `.glass-card` applies `backdrop-filter: blur(20px)`, a subtle border (`var(--bg-card-border)`), and rounded corners — used for disk overview, result sections, and toolbar panels.
- **Tauri-native titlebar**: `#titlebar` uses `-webkit-app-region: drag` and `user-select: none` to integrate with macOS window chrome; interactive buttons inside it opt out with `-webkit-app-region: no-drag`.
- **Layout**: Flexbox throughout (`display: flex`, `flex-direction: column` on `#app`, grid-like item rows). No CSS Grid is used.
- **Animations**: Keyframes defined inline (`slideUp`, `fadeIn`, `spin`, `pulse`, `toastIn/out`, `itemSlideIn`, `treeSlideDown`). Staggered entry delays are applied via `nth-child` selectors up to 13 items.
- **Custom scrollbar**: Only `#main-content::-webkit-scrollbar` is styled (6px width, transparent track, semi-transparent thumb).
- **SVG-based ring chart**: Disk usage is rendered via an inline SVG circle with `stroke-dasharray`/`stroke-dashoffset` animated through CSS transitions.
- **Tri-state checkboxes**: Pure CSS `.item-checkbox.checked` / `.indeterminate` states drawn with pseudo-elements (`::after` checkmark or dash).
- **Toast notifications**: Fixed-position container at top-right with success/error/info variants differentiated by left border color.
- **Responsive strategy**: None beyond the viewport meta tag. The app targets a fixed desktop window (`overflow: hidden` on body, fixed bottom action bar) — there are no media queries.

## Architecture & File Organization

- Single source of truth: `src/styles.css` (all styles).
- HTML structure lives in root `index.html` (not generated by a component framework); it contains the full DOM skeleton including tab panels (`#tab-cleanup`, `#tab-tree`, `#tab-files`), the disk overview card, scanning overlay, results sections, and toast container.
- No component-level style files exist; class names follow a flat BEM-ish naming convention (e.g., `.results-section.review .cleanup-item.selected`, `.tree-children.collapsed`).
- The Tauri backend (`src-tauri/`) has no styling code — all UI logic is frontend-only.

## Constraints & Enforced Rules

- **No external CSS framework or preprocessor**: `package.json` lists no Tailwind, Bootstrap, Sass, or PostCSS dependency; `vite.config.ts` is not shown but no such plugins are referenced elsewhere.
- **Design tokens must be consumed via CSS variables**: All colors, radii, and transitions reference `--*` variables rather than hard-coded values.
- **macOS native integration**: Any draggable region must use `-webkit-app-region: drag` and any interactive element within it must opt out with `-webkit-app-region: no-drag` (enforced by the Tauri window model).
- **Glass effect requires vendor-prefixed backdrop-filter**: Both standard `backdrop-filter` and `-webkit-backdrop-filter` are declared together on `.glass-card`, `.action-bar`, and `.toast` to support the Electron/Tauri Chromium engine.
- **Typography defaults to Apple system fonts**: The `font-family` declaration explicitly prioritizes SF Pro Display/Text and `-apple-system`, indicating the UI is intended for macOS.
